LuxRoster / Installation, workflow & limits +

Install

  1. Download the LuxRoster ZIP from the product page.
  2. In Blender Preferences, open Get Extensions → Install from Disk.
  3. Select the ZIP, enable LuxRoster and open the N-sidebar.
  4. Use the LuxRoster tab, or View → LuxRoster Light Manager for the wide interface.

A practical first pass

Search for a light or filter its collection. Check the lights you want to edit together, then apply the bulk setting. Solo a light to inspect its contribution; clear Solo to return to the original visibility state.

Scope

Works with native Point, Sun, Spot and Area lights. Linked light data appears read-only. The HDRI setup is created only when requested; unrelated World nodes are retained.

Book Rig Studio / Compatibility, installation & honest limits +

Version & compatibility

Version 0.26.0 targets Blender 4.2–5.1. The documented release run used Blender 5.1.2 on macOS. It does not certify every version or operating system in the target range. Blender 5.2 is excluded from this release.

Install & build

  1. Remove older copies and install one of the supplied ZIP formats, not both.
  2. Open N → Book Rig. Pick a preset, then Create / Update Book.
  3. Use Progress to animate. Rebuild after structural page-count or topology changes.

Portable does not mean every control

Save in master-slider mode for add-on-independent Progress control. Rebuilding topology, changing page counts and advanced generator editing still require Book Rig Studio.

Boundaries

This is deterministic mesh deformation, not cloth simulation or a general collision solver. Extreme curls and manually overlapping turns can intersect. The standard demo needs its relative texture folder; the comic demo uses self-contained procedural materials.

Origin Toolkit / Installation & first operation +

Install

In Blender Preferences → Get Extensions → Install from Disk, select the Origin Toolkit ZIP. Open the N-sidebar → Item → Origin Toolkit. Version 1.1.0 includes its Extension manifest and GPL-3.0-or-later license.

Place the origin

Select supported objects in Object Mode. Use Bottom, Center or Top, or choose Local/World and Min/Center/Max on each axis before Apply Custom Anchor. The operation restores the 3D Cursor and selection and supports Blender Undo. Ctrl + Alt + B performs local bottom-centre placement.

Verify the same failing frame twice, split enabled layers into test groups, then investigate the isolated layer’s effects. The source composition is preserved. I create original Blender add-ons for lighting, object workflow and procedural modeling/animation. My proposed first submission is LuxRoster 1.0, an existing Blender-native light manager for Cycles and Eevee. The portfolio shows its real interface, bulk editing, visibility-preserving Solo and World/HDRI controls. I also present Origin Toolkit 1.1, a packaged origin-placement tool with 27 Local/World anchors, and Book Rig Studio 0.26, a procedural book generator with real page geometry, nine rendered presets and a portable animation-control workflow. Book Rig Studio currently targets Blender 4.2–5.1, with release QA documented in Blender 5.1.2; it does not claim Blender 5.2 support. The proposed categories are lighting/workflow, object tools and modeling/animation. Indicative prices are US$9–19 for LuxRoster, US$5–9 for Origin Toolkit and US$29–49 for Book Rig Studio. Blender add-ons use GPL-3.0-or-later licensing. Each submission will include an installable package, written installation and usage instructions, accurate compatibility, original feature imagery and clear limitations. Client productions and the separate After Effects tools are portfolio context only and are not part of these Blender product downloads.
